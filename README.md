# 🛒 ShopEase - Online Shopping Website

ShopEase is a modern and responsive e-commerce website developed to provide a smooth online shopping experience. Users can browse products, search items, add products to a cart, and interact with an AI chatbot assistant for support.

## 🚀 Features

* 🔐 Login Interface
* 🏠 Attractive Home Page
* 🛍 Product Categories

  * Electronics
  * Fashion
  * Grocery
* 🔎 Product Search Functionality
* 🛒 Shopping Cart Management

  * Add products
  * Increase/decrease quantity
  * Remove items
  * Calculate total price
* 🤖 AI Chatbot Assistant
* 📞 Contact Support Page
* 📱 Responsive Design

## 🖥️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
* Google Fonts
* Local Storage

## ⚙️ How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Run `login.html` in your browser.

4. Login and explore the ShopEase website.
